### Canvas Discussion Analysis Web App
Using the discussion data obtained through the Canvas API or references to a referential database, this web application will display various analyses. Data visualization and interpretable measures will allow instructors to understand the general feelings and cognitive presence of their students.  

The app currently displays the sentiment analysis of discussions in the course _sstaudaher3 Sandbox 20190716_ in a table format.

### Technologies
**Flask**: framework for Python web applications  
**HTML**: defines the meaning and structure of the web application content  
**CSS**: describes the presentation for HTML documents  
**React**: JavaScript library used to build interactive web applications

### How To Run the App
Run "python app.py" in a terminal and then navigate to http://localhost:5000 to view the web application locally.
