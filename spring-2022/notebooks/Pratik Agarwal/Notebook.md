- Points
  - AI Course has matured and the kind of things that we can provide them as insights regarding sentiment or otherwise, the TAs already know that
    - It could be more helpful for a younger class where the behaviour and feedback and sentiment is not immediately obvious
  - PARQR team is already making extensions on Piazza to help the instructor team operate more efficiently - Assigning questions, identifying duplicates, making suggestions etc...
  - Cognitive presence analysis could probably be of some use (doubtful) in cases where new comments set Piazza trigger to unresolved, or say getting a TAs attention to something that requires the instructor's presence.
  - A more useful case would be topic modeling. Coz if the course stays same, the questions repeat as well from students, so if from previous semester's posts we can create a cluster of posts/threads together corresponding to a given topic and create FAQs from that, that could help significantly reduce the workload of the instructor team. We'll need multiple semesters data for the same but first for the Spring 2020 sem too we can try doing this.
