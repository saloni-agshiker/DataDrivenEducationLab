Sample scripts to do basic functions required for this VIP team.

To get started copy creds_example.py to creds.py

**NOTE: NEVER UPLOAD CREDENTIALS TO GITHUB, creds.py IS IN .GITIGNORE AND WILL NOT BE UPLOADED.**

Then, copy your credentials into creds.py. You should now be able to run nlp_analysis, which will print out the sentences with the most negative sentiment from the edX forums.

This also includes piazza_scrape, which will scrape piazza given credentials
