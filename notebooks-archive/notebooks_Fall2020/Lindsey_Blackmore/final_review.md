I believe this semester was a huge success. We accomplished more work than in
the previous semesters. The communication between the data science and web
development team was great and lead to a more cohesive project. We have highlighted
the next steps for future teams that work on this project. The web application
has a well defined architecture that abstracts the backend and frontend. The
README.md for the application outlines how to run it locally. Sambhav has outlined
the next steps for the dynamic routing.

For even more success, the Trello board should be updated more frequently. Future
subteams should consider conducting weekly code reviews and pull requests when
using version control. I also do not think there needs to be more than one project
manager as this lead to difficulty in dividing the work. In addition, having the
project managers also serve as another role was difficult because there seemed
to be almost twice the amount of work.
