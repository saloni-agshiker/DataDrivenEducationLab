# Starting the Front End  

In the react-flask-app directory, run 'yarn start'  
Navigate to http://localhost:3000 or http://localhost:3000/time in a browser

# Starting the Back End  

In the react-flask-app directory, 'cd api'  
Activate the virtual environment by running venv\Scripts\activate (Windows)  
Execute 'set FLASK_APP=api.py'  
Execute 'flask run'
